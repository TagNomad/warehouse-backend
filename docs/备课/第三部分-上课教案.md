# 第三部分上课教案（第 11 周周三 1–4 节）

4 课时，周三上午一次讲完。投影 [第三部分-讲义.html](./第三部分-讲义.html)。库存和入库不拆成两节。

先用仓库格子和 `SKU-001` 把问题说成两句：每个格子各有多少，单据完成时数量和状态是否一起变。

然后按讲义里的三张图走接口，不要再打开源码文件：

1. `POST /inbound-orders`：Controller 不传字段，Service 先插入再把单号改成 `IN-主键`。
2. `POST /inbound-orders/{id}/lines`：三个字段原样传下去，编码在 Service 换成货品主键和库位主键，再写入行。
3. `POST /inbound-orders/{id}/complete`：按货品 + 库位写入 `inventory`，并在同一个事务里把状态改成 `COMPLETED`。

第三部分那一版的结果图还在讲义里：两次完成都是 400，`on_hand` 是 18，两张单仍是草稿。这一版的结果图是 `inventory` 两行 10 和 8，两张单是 `COMPLETED`。

讲义最后一节是把「第三部分改良版」合并进「第三部分」：源分支改良版，目标分支第三部分，网页上创建并合并。
