# 第四部分上课教案（第 14 周，6 课时）

投影 [第四部分-讲义.html](./第四部分-讲义.html)。分支「第四部分」，没有改良版。老师演示，学生下载代码对照页面、代码、MinIO 控制台、数据库看。

课前：老师电脑 `docker compose -f docker-compose.dev.yml up -d mysql adminer redis minio`，后端 IDEA 手动启动，前端切到「第四部分」。浏览器另开一个标签 `http://localhost:9001`，用 `minioadmin` / `minioadmin` 登录。准备两个内容不同、都叫 `收货单.txt` 的文件。提醒学生课前装好 Silo（讲义第 1 节）。

演示时改 IDEA 的 Program arguments 再重启，每个案例做完把参数去掉。

## 周一（2 课时）：MinIO 和上传、下载

1. 第 1 节（约 40 分钟）：对象、key、桶三个词；本机磁盘、MySQL、MinIO 那张对比表，讲清为什么文件不放后端机器上、也不放表里；Compose 里的 minio 服务、Windows 上 `silo.exe server D:\minio-data --console-address :9001`；控制台走一遍；两个开关过一遍。
2. 第 2 节（约 40 分钟）：IN-1 加一行 SKU-003 / A-01-01 / 10，上传 `收货单.txt`。按讲义从前端 `FormData` 讲到 Controller、Service、`putObject`、Mapper；Adminer 里查 `inbound_attachment`，控制台里点到 `wms/inbound/IN-1/`，对上 key。
3. 第 3 节（约 20 分钟）：点「下载」，讲 Service 按 `file_path` 找内容、Controller 用 `Content-Disposition` 还原名。

## 周三（4 课时）：两个问题

1. 第 4 节（约 70 分钟）：加 `--app.lesson.file-store=local` 重启，新建 IN-4 上传，表格里是本机绝对路径，下载正常；把项目下 `data/attachments` 改名；去掉参数重启，IN-4 再传一次；两个都下载，本机路径的 400 `FILE_NOT_FOUND`，key 的 200。讲表和文件分开存时，表里该记什么。演示完把目录改回来。
2. 第 5 节（约 70 分钟）：加 `--app.lesson.file-key=filename` 重启，新建 IN-3，先后传两个 `收货单.txt`，两个都下载，都是第二张；控制台 `wms/inbound/IN-3/` 下只有一个对象。去掉参数重启，新建一张单同样传两次，各下各的。Adminer 里 `SELECT … FROM inbound_attachment ORDER BY id` 对照两个问题。提一句 `../` 文件名，让学生看 `AttachmentDefectPathTest`。
3. 第 6、7 节和答疑（剩余时间）：作业二选「文件」的同学按第 7 节自查。
