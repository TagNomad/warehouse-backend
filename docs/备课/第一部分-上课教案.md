# 第一部分上课教案（第 10 周，6 课时）

分支「第一部分」。老师演示，学生下载代码对照着看。

## 第一次课（2 课时）：拿到代码，把系统跑起来

投影 [第一部分-讲义.html](./第一部分-讲义.html) 第 1–6 节。老师按讲义顺序演示，学生下载代码对照着看，课上不要求学生跟着做。

课前：老师电脑上 MySQL 和 Adminer 在 Docker 里（`docker compose -f docker-compose.dev.yml up -d mysql adminer`），后端用 IDEA 手动启动，前端 `npx pnpm@9 dev` 起在 5173，登录好。

1. 第 1 节（约 5 分钟）：打开 5173，展开 WH-001 的库区库位，说清前端、后端、MySQL 三样东西。
2. 第 2 节（约 20 分钟）：Git 的仓库、提交、分支各一句话。演示安装 GitHub Desktop、克隆后端和前端、切到「第一部分」。
3. 第 3 节（约 25 分钟）：后端怎么跑。重点讲账号密码不是 root 时的 `application-local.properties`，演示 IDEA 启动、控制台的 `Started`、数据库里自动建好的表、health 返回 UP。
4. 第 4 节（约 10 分钟）：前端两条命令，`/api` 怎么转到 8080。
5. 第 5 节（约 25 分钟）：「库区库位」一个案例，从前端代码讲到三张表，每一层停在截图上讲。
6. 第 6 节（约 10 分钟）：在 GitHub Desktop 和 Gitee 网页上演示分支、提交、Pull Request。

课后：学生在自己电脑上把前后端跑起来，截一张展开库区库位的页面。

## 第二次课（4 课时）：货品与入库

投影 [第一部分-讲义.html](./第一部分-讲义.html) 第 7–11 节。和第一次课用同一个分支，不用另起环境。老师演示，学生对照页面、代码、数据库看。

课前：在 Adminer（`http://localhost:8081`，服务器 `mysql`，root / root，库 `pro_skill`）里清空入库数据，让主键从 1 开始：

```sql
TRUNCATE TABLE inbound_order_line;
TRUNCATE TABLE inbound_order;
TRUNCATE TABLE inventory;
```

1. 第 7 节（约 15 分钟）：货品页、入库页各点一遍，说这一部分加了货品和入库。
2. 第 8 节（约 15 分钟）：四张表各存什么，在 Adminer 里打开看列。
3. 第 9 节（约 90 分钟）：案例。先在入库页点三下，每点一下到 Adminer 看多了什么。再跟着「完成入库」，前端 → Controller → Service → Mapper → `inventory`，每一层停在截图上讲。最后同一个库位再入 5 个，看 `inventory` 那一行变成 15。
4. 第 10 节（约 30 分钟）：剩下四个接口不展开，指给学生看文件在哪，挑一个（新建货品）带着读一遍。
5. 第 11 节和答疑（剩余时间）。
