# 第二部分上课教案（第 10 周，4 课时）

投影 [第二部分-讲义.html](./第二部分-讲义.html)。和第一部分同一个分支「第二部分」，不用另起环境。老师演示，学生对照页面、代码、数据库看。

课前：在 Adminer（`http://localhost:8081`，服务器 `mysql`，root / root，库 `pro_skill`）里清空入库数据，让主键从 1 开始：

```sql
TRUNCATE TABLE inbound_order_line;
TRUNCATE TABLE inbound_order;
TRUNCATE TABLE inventory;
```

1. 第 1 节（约 15 分钟）：货品页、入库页各点一遍，说这一部分加了货品和入库。
2. 第 2 节（约 15 分钟）：四张表各存什么，在 Adminer 里打开看列。
3. 第 3 节（约 90 分钟）：案例。先在入库页点三下，每点一下到 Adminer 看多了什么。再跟着「完成入库」，前端 → Controller → Service → Mapper → `inventory`，每一层停在截图上讲。最后同一个库位再入 5 个，看 `inventory` 那一行变成 15。
4. 第 4 节（约 30 分钟）：剩下四个接口不展开，指给学生看文件在哪，挑一个（新建货品）带着读一遍。
5. 第 5 节和答疑（剩余时间）。
