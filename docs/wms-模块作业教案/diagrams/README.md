# draw.io 图源说明 — FR-01 仓库与库位管理（完整版）

## 打开与导出

1. 浏览器 <https://app.diagrams.net> 或 VS Code **Draw.io Integration**
2. 修改文字后：**文件 → 导出为 → PNG**（宽度 ≥ 1200px）
3. Word 插入图片并写题注（与下表图号一致）
